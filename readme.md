# Pin Sidebar

- **Find pin**: Suchleiste über den Essentials. Filtert Pins/Bookmarks, klappt passende Folder auf, x leert die Suche.
- **Dock-Dot**: Geöffnete (geladene) Pins bekommen links einen Punkt.
- **Trenner**: Beim Hovern erscheint links auf dem Trenner ein Pin-Symbol. Aktiv = Trenner fixiert und per Drag zwischen Pins/Foldern verschiebbar. Inaktiv = Trenner am Ende der Pin-Liste.

Hinweis: Lokal installierte Sine-Mods mit JS brauchen `sine.allow-unsafe-js = true` (about:config).
